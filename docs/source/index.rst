Welcome to SWEPT's documentation!
===================================

``SWEPT`` (**S**\imulator for **WE**\ak **L**\ensing **P**\ower spectrum **T**\omography) is a simulation package that
performs an end-to-end cosmological weak lensing (cosmic shear) power spectrum analysis.

- Map-based simulation of mock weak lensing survey/catalogue
- Tomographic Pseudo-:math:`C_{\ell}` measurement
- (Gaussian) likelihooad analysis to measure constraints of :math:`3\times2`\pt Pseudo-:math:`C_{\ell}` data vector on
  dark energy :math:`(w_{0},w_{a})` parameters
